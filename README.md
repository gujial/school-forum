# “可圈可点”校园论坛平台

![icon](./public/icon.png)<br/>
可圈可点校园论坛平台

## 使用到的开源库

- 前端与框架
  - [Nuxt 4](https://nuxt.com/)
  - [Nitro](https://nitro.unjs.io/)
  - [Vue](https://vuejs.org/)
  - [Vuetify 3](https://vuetifyjs.com/zh-Hans/)
  - [Vuetify Nuxt Module](https://vuetify-nuxt-module.netlify.app/)

- Nuxt 模块
  - [@sidebase/nuxt-auth](https://sidebase.io/nuxt-auth/getting-started)
  - [@nuxtjs/i18n](https://i18n.nuxtjs.org/)
  - [@nuxtjs/color-mode](https://color-mode.nuxtjs.org/)
  - [@nuxt/eslint](https://github.com/nuxt/eslint)

- 实用库与组件
  - [@vueuse/core](https://vueuse.org/)
  - [Vue I18n](https://vue-i18n.intlify.dev/)
  - [Vditor](https://b3log.org/vditor/)
  - [Material Design Icons (mdi)](https://pictogrammers.com/library/mdi/)

- 后端与服务
  - [mysql2](https://github.com/sidorares/node-mysql2)
  - [bcryptjs](https://github.com/dcodeIO/bcrypt.js)
  - [jsonwebtoken](https://github.com/auth0/node-jsonwebtoken)
  - [formidable](https://github.com/node-formidable/formidable)
  - [fluent-ffmpeg](https://github.com/fluent-ffmpeg/node-fluent-ffmpeg)
  - [dotenv](https://github.com/motdotla/dotenv)

- 其他开发依赖
  - [ESLint](https://eslint.org/)、[eslint-plugin-vue](https://eslint.vuejs.org/)、[@typescript-eslint](https://typescript-eslint.io/)
  - [Prettier](https://prettier.io/)
  - [TypeDoc](https://typedoc.org/)（含 typedoc-plugin-markdown）

## 相关命令

### 格式化代码
```bash
pnpm run lint --fix
```

### 更新 api 文档
```bash
pnpm run docs:api
```
