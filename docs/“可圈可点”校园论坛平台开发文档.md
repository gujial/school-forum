## 开发流程规范
主分支名字是`dev`是个小失误🤯，把它当成主分支就是了
### 提交
本项目仓库为[“可圈可点”校园论坛平台](https://github.com/gujial/school-forum)，进行功能开发时遵循以下流程：
- 在远程仓库（Github）中创建新分支，命名为`feature/<功能名>`（尽量使用英文）
- 克隆仓库到本地并切换到新分支中
- 进行功能开发和**测试**，在 Github 中创建 Pull Request 等待 Code Review 后合并到主分支
> 每次开发一个新功能都需要创建一个新分支。创建新分支要从最新一次提交创建，保证与主分支同步。
> 尽量勤提交，并写好提交信息，[规范](https://ruanyifeng.com/blog/2016/01/commit_message_change_log.html)

### 代码风格
只做基本要求：
- 变量名、函数名等使用英文
- 不压行，适当空行
- 嵌套超过四层时尽量将内部逻辑提取到单独的函数中
- 最后随便找个代码格式化程序搞一下
