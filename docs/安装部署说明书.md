# "可圈可点"校园论坛平台安装部署说明书

## 1. 概述

### 1.1 项目简介

"可圈可点"校园论坛平台是一个基于 Nuxt.js 3 和 OceanBase 数据库的现代化校园社交平台，支持用户发帖、评论、点赞、关注、私信等核心功能。

### 1.2 技术架构

- **前端框架**: Nuxt.js 3 (Vue.js 3)
- **UI组件库**: Vuetify 3
- **后端服务**: Node.js + TypeScript
- **数据库**: OceanBase (MySQL 兼容)
- **容器化**: Docker + Docker Compose
- **进程管理**: PM2
- **认证系统**: JWT + bcryptjs

---

## 2. 环境要求

### 2.1 系统要求

- **操作系统**: Linux (推荐 Ubuntu 20.04+ / CentOS 8+ / Arch Linux)
- **内存**: 最低 4GB，推荐 8GB+
- **存储**: 最低 20GB 可用空间
- **网络**: 支持 HTTP/HTTPS 访问

### 2.2 软件依赖

- **Docker**: 20.10+
- **Docker Compose**: 2.0+
- **Node.js**: 18.0+ (开发环境)
- **pnpm**: 8.0+ (推荐包管理器)

### 2.3 端口要求

- **应用服务**: 3000
- **数据库**: 2881 (SQL), 2883 (RPC)

## 3. 快速部署 (Docker)

### 3.1 环境准备

```bash
# 安装 Docker (Ubuntu/Debian)
curl -fsSL https://get.docker.com -o get-docker.sh
sudo sh get-docker.sh

# 安装 Docker Compose
sudo curl -L "https://github.com/docker/compose/releases/latest/download/docker-compose-$(uname -s)-$(uname -m)" -o /usr/local/bin/docker-compose
sudo chmod +x /usr/local/bin/docker-compose

# 启动 Docker 服务
sudo systemctl start docker
sudo systemctl enable docker
```

### 3.2 项目部署

```bash
# 克隆项目
git clone <repository-url>
cd school-forum

# 创建环境配置文件
cp .env.example .env

# 编辑环境变量
nano .env
```

### 3.3 环境变量配置

```bash
# 数据库配置
DB_ROOT_PASSWORD=your_secure_password
DB_NAME=school_forum
DB_PASSWORD=forum_user_password

# JWT 密钥
JWT_SECRET=your_very_long_random_jwt_secret_key

# LLM API 配置
LLM_API_URL=https://api.deepseek.com
LLM_MODEL=deepseek-chat
DEEPSEEK_API_KEY=your_api_key

# 应用配置
NODE_ENV=production
PORT=3000
```

### 3.4 启动服务

```bash
# 构建并启动所有服务
docker-compose up -d

# 查看服务状态
docker-compose ps

# 查看日志
docker-compose logs -f

# 仅启动数据库 (用于开发)
docker-compose up -d oceanbase
```

### 3.5 初始化数据库

```bash
# 等待数据库启动完成 (约 2-3 分钟)
docker-compose logs oceanbase

# 执行数据库初始化脚本(建议根据具体选用的数据库使用 db.sql 中的语句手动初始化)
# docker-compose exec app npm run db:init

# 检查数据库状态
docker-compose exec app npm run db:status
```

## 4. 手动安装部署

### 4.1 安装 Node.js 环境

```bash
# 使用 nvm 安装 Node.js
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.0/install.sh | bash
source ~/.bashrc

# 安装 Node.js 20
nvm install 20
nvm use 20
nvm alias default 20

# 安装 pnpm
npm install -g pnpm
```

### 4.2 安装 OceanBase 数据库

```bash
# 下载 OceanBase 社区版
wget https://github.com/oceanbase/oceanbase/releases/download/v4.2.0.0/oceanbase-ce-4.2.0.0-100120230430202026.el7.x86_64.rpm

# 安装 OceanBase
sudo rpm -ivh oceanbase-ce-4.2.0.0-100120230430202026.el7.x86_64.rpm

# 初始化 OceanBase
sudo obd cluster deploy obcluster -c /etc/obd/example/mini-local-example.yaml
sudo obd cluster start obcluster

# 创建数据库和用户
mysql -h127.1 -P2881 -uroot
```

```sql
-- 创建数据库
CREATE DATABASE school_forum CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 创建用户
CREATE USER 'forum_user'@'%' IDENTIFIED BY 'forum_pass';
GRANT ALL PRIVILEGES ON school_forum.* TO 'forum_user'@'%';
FLUSH PRIVILEGES;

-- 退出
EXIT;
```

### 4.3 项目安装

```bash
# 克隆项目
git clone <repository-url>
cd school-forum

# 安装依赖
pnpm install

# 创建环境配置文件
cp .env.example .env

# 编辑环境变量
nano .env
```

### 4.4 环境变量配置


### 4.5 构建和启动

## 5. 配置说明

### 5.1 数据库配置

```typescript
// server/config/database.ts
const poolConfig = {
  host: process.env.DB_HOST || 'localhost',
  port: parseInt(process.env.DB_PORT || '3306'),
  user: process.env.DB_USER || 'root',
  password: process.env.DB_PASSWORD || '',
  database: process.env.DB_NAME || 'school_forum',
  charset: 'utf8mb4',
  waitForConnections: true,
  connectionLimit: 10,
  queueLimit: 0
}
```

## 6. 部署后配置

### 6.1 反向代理配置 (Nginx)

```nginx
server {
    listen 80;
    server_name your-domain.com;
    
    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
    
    # 静态文件缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```

### 6.2 SSL 证书配置

```bash
# 安装 Certbot
sudo apt install certbot python3-certbot-nginx

# 获取 SSL 证书
sudo certbot --nginx -d your-domain.com

# 自动续期
sudo crontab -e
# 添加: 0 12 * * * /usr/bin/certbot renew --quiet
```

### 6.3 防火墙配置

```bash
# UFW 防火墙配置
sudo ufw allow 22/tcp    # SSH
sudo ufw allow 80/tcp    # HTTP
sudo ufw allow 443/tcp   # HTTPS
sudo ufw enable

# 或使用 iptables
sudo iptables -A INPUT -p tcp --dport 80 -j ACCEPT
sudo iptables -A INPUT -p tcp --dport 443 -j ACCEPT
sudo iptables -A INPUT -p tcp --dport 22 -j ACCEPT
```
