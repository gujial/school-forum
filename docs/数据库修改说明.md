# 数据库修改说明

## 修改概述

将原本使用SQLite数据库（通过db0库）的实现修改为使用MySQL数据库连接池。

## 主要修改内容

### 1. 新增MySQL数据库配置

#### 数据库连接池配置 (`server/config/database.ts`)
- **功能**: 创建和管理MySQL连接池
- **特性**: 
  - 连接池管理，提高性能
  - 自动重连机制
  - 超时处理
  - 事务支持

#### 数据库工具类 (`server/util/database.ts`)
- **功能**: 提供与原来`useDatabase()`兼容的接口
- **特性**:
  - 支持模板字符串SQL查询
  - 参数化查询，防止SQL注入
  - 事务支持
  - 错误处理

### 2. 数据库初始化脚本修改

#### 初始化脚本 (`scripts/init-db.js`)
- 从SQLite改为MySQL
- 添加数据库连接测试
- 支持事务执行多条SQL语句

#### 数据库结构 (`scripts/db.sql`)
- 修改表结构以匹配当前应用需求
- 使用MySQL语法
- 添加必要的外键约束

### 3. 环境配置

#### 环境变量文件 (`env.example`)
- 数据库连接配置
- JWT密钥配置
- 服务器环境配置

#### 配置文件更新 (`nuxt.config.ts`)
- 移除实验性数据库配置
- 使用自定义MySQL连接池

### 4. 依赖更新

#### 新增依赖
- `mysql2`: MySQL数据库驱动

#### 移除依赖
- `db0`: SQLite数据库库
- `better-sqlite3`: SQLite驱动

## 数据库表结构

### Users表
```sql
CREATE TABLE Users (
    user_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL UNIQUE,
    email VARCHAR(100) NOT NULL UNIQUE,
    password VARCHAR(255) NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);
```

### Avatar表
```sql
CREATE TABLE Avatar (
    user_id BIGINT PRIMARY KEY,
    avatar_url TEXT,
    FOREIGN KEY (user_id) REFERENCES Users(user_id)
);
```

### Tweets表
```sql
CREATE TABLE Tweets (
    tweet_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    content TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES Users(user_id)
);
```

### Comments表
```sql
CREATE TABLE Comments (
    comment_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    tweet_id BIGINT NOT NULL,
    user_id BIGINT NOT NULL,
    content TEXT NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (tweet_id) REFERENCES Tweets(tweet_id),
    FOREIGN KEY (user_id) REFERENCES Users(user_id)
);
```

### Media表
```sql
CREATE TABLE Media (
    media_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    tweet_id BIGINT,
    media_url TEXT NOT NULL,
    media_type VARCHAR(10) NOT NULL,
    FOREIGN KEY (tweet_id) REFERENCES Tweets(tweet_id)
);
```

### Likes表
```sql
CREATE TABLE Likes (
    like_id BIGINT PRIMARY KEY AUTO_INCREMENT,
    user_id BIGINT NOT NULL,
    tweet_id BIGINT NOT NULL,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES Users(user_id),
    FOREIGN KEY (tweet_id) REFERENCES Tweets(tweet_id),
    UNIQUE KEY unique_user_tweet (user_id, tweet_id)
);
```

## 部署步骤

### 1. 环境准备
```bash
# 安装依赖
pnpm install

# 复制环境变量文件
cp env.example .env
```

### 2. 数据库配置
```bash
# 编辑 .env 文件，设置数据库连接信息
DB_HOST=localhost
DB_PORT=3306
DB_USER=root
DB_PASSWORD=your_password
DB_NAME=school_forum
```

### 3. 数据库初始化
```bash
# 测试数据库连接
pnpm run db:test

# 初始化数据库表
pnpm run db:init
```

### 4. 启动应用
```bash
# 开发环境
pnpm run dev

# 生产环境
pnpm run build
```

## 技术特点

### 连接池管理
- **连接复用**: 减少连接创建和销毁的开销
- **自动重连**: 网络断开时自动重连
- **连接限制**: 控制最大连接数，防止资源耗尽
- **超时处理**: 设置连接和查询超时

### 安全性
- **参数化查询**: 防止SQL注入攻击
- **事务支持**: 确保数据一致性
- **错误处理**: 完善的错误处理机制

### 性能优化
- **连接池**: 提高并发性能
- **预处理语句**: 提高查询性能
- **索引优化**: 合理的表结构和索引设计

## 优势

1. **更好的并发性能**: MySQL连接池支持更高的并发访问
2. **更强的数据一致性**: 支持ACID事务
3. **更好的扩展性**: MySQL支持更复杂的查询和更大的数据量
4. **更好的管理工具**: MySQL有丰富的管理和监控工具
5. **更好的备份恢复**: MySQL支持多种备份和恢复策略

## 注意事项

1. **环境变量**: 确保正确配置数据库连接信息
2. **数据库权限**: 确保数据库用户有足够的权限
3. **字符集**: 使用utf8mb4字符集支持emoji等特殊字符
4. **备份**: 定期备份数据库数据
5. **监控**: 监控数据库连接池状态和性能
